🚀 Quick Start Guide

Follow these steps to run the applications

1

Start Laravel Backend

Open terminal and navigate to Admin Panel folder, then run the artisan serve command.

cd "Admin Panel\kivicare-laravel-web-v1.8.2\kivicare-laravel-web-v1.8.2"
php artisan serve --host=0.0.0.0 --port=8000
2

Access Admin Panel

Open your browser and navigate to the admin panel URL.

http://192.168.100.87:8000
3

Run Patient App (Mobile)

Connect your Android device via USB with USB debugging enabled, then run Flutter.

cd C:\kivicare-patient
flutter run
4

Run Admin App (Mobile)

Connect your Android device via USB with USB debugging enabled, then run Flutter.

cd C:\kivicare-admin
flutter run

🔗 API Configuration

Connect Mobile Apps to Admin Panel

💡 Both mobile apps need to connect to the Laravel backend. Make sure to update the DOMAIN_URL in configs.dart
// File: configs.dart (in both apps)

// For local development:
const DOMAIN_URL = "http://192.168.100.87:8000";

// For production (replace with your domain):
const DOMAIN_URL = "https://yourdomain.com";

🔧 Troubleshooting

Common issues and solutions

Issue Solution
Images not loading in Mobile Apps Ensure APP_URL in Laravel .env matches the IP address used in configs.dart
Cannot connect to server Check if Laravel server is running and firewall allows port 8000
App crashes on startup Run flutter clean then flutter pub get
Payment methods not showing Enable payment methods in Admin Panel → Settings → Payment Settings
Login failed error Check DOMAIN_URL in configs.dart and ensure server is running
